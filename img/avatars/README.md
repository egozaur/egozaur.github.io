# Awatary graczy PL3Y

Pliki `1.svg` … `10.svg`: detektyw, agentka, moneta, kurczak w koronie, lupa, maska wenecka, as pik, kot noir,
lis w muszce, sowa z monoklem. Wypełnione złote sylwetki na ciemnym tle (wspólna oprawa, czytelne także w 28 px).
Ekran gracza (`/auth.js`) pokazuje je w karuzeli, a gry przy nicku (`PL3Y.avatarUrl(i)`).

Podmiana: wgraj własny obrazek pod tą samą nazwą (np. nowy `3.svg`). Jeśli chcesz PNG/WEBP zamiast SVG,
zmień rozszerzenie w funkcji `avatarUrl` w `/auth.js` (jedno miejsce) i wgraj wszystkie 10 plików w tym formacie.
Najlepiej kwadrat, motyw w środku (obrazek jest przycinany do koła). Nie zmieniaj kolejności: gracze mają zapisany numer.
