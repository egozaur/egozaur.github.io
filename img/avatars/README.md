# Awatary graczy PL3Y

Pliki `1.svg` … `10.svg` to tymczasowe obrazki z numerem. Ekran gracza (`/auth.js`) pokazuje je w karuzeli,
a gry wyświetlają je przy nicku (`PL3Y.avatarUrl(i)`).

Podmiana: wgraj własny obrazek pod tą samą nazwą (np. nowy `3.svg`). Jeśli chcesz PNG/WEBP zamiast SVG,
zmień rozszerzenie w funkcji `avatarUrl` w `/auth.js` (jedno miejsce) i wgraj wszystkie 10 plików w tym formacie.
Najlepiej kwadrat, min. 256×256, motyw w środku (obrazek jest przycinany do koła).
